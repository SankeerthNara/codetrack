# CodeTrack — Android build

This project has an `android/` folder generated by Capacitor. It wraps the
app's static export (`out/`) in a native Android shell, so it installs and
runs like any other app — no separate server needed, everything (the
LeetCode/GitHub/Codeforces syncing included) runs on-device.

## ⚠️ Required first step: install dependencies

**Before opening `android/` in Android Studio, open a terminal in the
project root (not the `android` folder) and run:**

```bash
npm install
```

This is not optional. The `node_modules` folder isn't included in the zip
(it's 800MB+), but the Android project's Capacitor library is a **local**
Gradle module that lives at `node_modules/@capacitor/android/capacitor` —
without running `npm install` first, Gradle can't find it and the build
fails with something like:

```
No matching configuration of project :capacitor-android was found
```

If you (or an in-IDE AI assistant) previously tried to "fix" that error by
pointing the dependency at a Maven coordinate instead — e.g.
`com.getcapacitor:android:6.2.1` — undo that. That package doesn't exist on
Maven; it'll just produce a *different* error ("Could Not Resolve
com.getcapacitor:android:6.2.1"). The correct fix is always `npm install`,
not swapping the dependency source. This zip's `android/` folder is already
back to the correct configuration (a local project dependency), so if you're
using these files fresh you don't need to change anything — just run
`npm install` first.

## One-time setup

1. Run `npm install` in the project root (see above).
2. Install **Android Studio**: https://developer.android.com/studio
   (You need this on a computer — Android Studio doesn't run on the phone
   itself. The phone is just where the finished app gets installed.)
3. Open Android Studio → **Open** → select the `android/` folder inside this
   project (not the project root — the `android` folder specifically).
4. Let Android Studio finish "Gradle sync" the first time you open it — it'll
   download some build tools automatically. This can take a few minutes.

## Installing on your phone

1. On your phone: **Settings → About phone**, tap "Build number" 7 times to
   unlock **Developer options**. Then go to **Settings → Developer options**
   and turn on **USB debugging**.
2. Plug your phone into your computer with a USB cable. Your phone should
   show a popup asking to allow USB debugging — accept it.
3. In Android Studio, your phone should now appear in the device dropdown
   near the top toolbar (instead of an emulator). Select it.
4. Click the green **Run ▶** button. Android Studio builds the app and
   installs it directly on your phone — it'll open automatically.

That's it — from then on the app is just installed on your phone like any
other app, launchable from the home screen/app drawer without needing your
computer again.

## If you'd rather sideload an APK (no cable needed)

In Android Studio: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
It'll build a file at `android/app/build/outputs/apk/debug/app-debug.apk`.
Transfer that file to your phone (email, Drive, USB, etc.) and open it there
to install — you'll need to allow "install from unknown sources" for
whichever app you use to open the file.

## Re-building after code changes

If you (or I) change the web code later, the Android project needs to be
re-synced with the new build:

```bash
npm install           # only needed if this is a fresh clone / node_modules is missing
npm run build          # rebuilds the static export into out/
npx cap sync android   # copies out/ into the Android project + updates plugins
```

Then re-run from Android Studio as above.

## If Android Studio's built-in AI assistant offers to "fix" a build error

Be cautious — in this project's case, its suggested fix (switching the
Capacitor dependency from a local project reference to a Maven coordinate)
made things worse because it was solving the wrong problem. The actual
missing piece was just `npm install`. If a build error mentions
`capacitor-android` or `com.getcapacitor`, run `npm install` in the project
root first and re-sync before accepting any other change.

## Notes

- This is a fully offline-capable static build — there's no backend server.
  All the LeetCode/GitHub/Codeforces API calls happen directly from the
  device.
- LeetCode's API normally blocks browser-based cross-origin requests, which
  is why `capacitor.config.ts` enables the `CapacitorHttp` plugin — it routes
  network calls through native Android code instead of the WebView, which
  sidesteps that restriction. This only takes effect in the actual installed
  app; it won't work if you preview `out/` in a regular desktop browser.
- If LeetCode still shows "Sync failed" after installing on your phone, it's
  most likely LeetCode's Cloudflare bot protection rejecting the request —
  tap **Sync Now** again after a bit; it doesn't always trigger. GitHub and
  Codeforces don't have this issue since their public APIs allow direct
  cross-origin requests.
- Platform connections and settings save to on-device storage (see the
  earlier local-storage change), so they're private to your phone and won't
  sync anywhere else.
- The app id is `com.codetrack.app` and the display name is "CodeTrack" —
  both set in `capacitor.config.ts` if you want to change them (re-run
  `npx cap sync android` after editing).
